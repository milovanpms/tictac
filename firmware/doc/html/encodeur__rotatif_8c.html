Detailed Description

Implémentation de la gestion de l'encodeur rotatif avec détection de direction.

Author
Thomas Pineau et Milovan Paget

Ce module gère un encodeur rotatif en détectant la direction de rotation grâce à une machine d'états et en implémentant un système d'anti-rebond pour éviter les fausses détections.

◆ encoder_callback()

void encoder_callback ( uint8_t pin)

Fonction de callback pour traiter les interruptions de l'encodeur rotatif.

Fonction de callback pour traiter les interruptions de l'encodeur.

Cette fonction implémente une machine d'états pour détecter la direction de rotation de l'encodeur. Elle utilise les transitions entre états pour déterminer si la rotation est horaire (CW) ou anti-horaire (CCW).

Parameters
pinNuméro du pin ayant généré l'interruption (non utilisé dans l'implémentation)
Precondition
Les GPIO PA12 et PB5 doivent être configurés avec interruptions
HAL_GetTick() doit retourner un timestamp valide
La fonction externe EPD_MenuEncoderCallback() doit être définie
Postcondition
encoderPos est incrémenté/décrémenté selon la direction
lastEncoderState et lastDebounceTime sont mis à jour
EPD_MenuEncoderCallback est appelée avec la direction détectée
Note
Anti-rebond de 5ms pour filtrer les parasites électriques

◆ readEncoder()

int readEncoder ( )

Lit la valeur codée actuelle de l'encodeur rotatif.

Cette fonction lit les états des deux pins de l'encodeur rotatif et combine leurs valeurs pour former un code sur 2 bits.

Returns
int Valeur codée de l'encodeur (0-3)
  • 0 (00) : les deux pins sont à 0
  • 1 (01) : pin gauche=0, pin droit=1
  • 2 (10) : pin gauche=1, pin droit=0
  • 3 (11) : les deux pins sont à 1
Precondition
Les GPIO BTN_GAUCHE_GPIO/BTN_GAUCHE_PIN et BTN_DROIT_GPIO/BTN_DROIT_PIN doivent être configurés en entrée
Postcondition
Aucun changement d'état, fonction de lecture pure
Note
MSB = pin gauche, LSB = pin droit
Formule : (MSB << 1) | LSB

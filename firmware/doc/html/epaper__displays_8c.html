Detailed Description

Gestion de l'affichage e-paper avec machine à états et navigation de menu.

Author
Thomas Pineau et Milovan Paget

Ce fichier implémente une machine à états pour la gestion de l'affichage e-paper, incluant la navigation dans les menus, l'affichage des différentes vues (pouls, pas, NFC) et la gestion des interactions utilisateur via boutons et encodeur rotatif.

◆ EPD_HandleMenuNavigation()

void EPD_HandleMenuNavigation ( void )

Gestion de la navigation dans le menu via les boutons.

Cette fonction vérifie périodiquement l'état du bouton central pour détecter les sélections d'éléments de menu et déclenche les transitions d'état appropriées. Elle gère également la mise à jour de l'affichage du menu.

Precondition
L'état actuel doit être IDLE
Postcondition

◆ EPD_MenuEncoderCallback()

void EPD_MenuEncoderCallback ( int direction)

Callback appelé par l'encodeur rotatif pour changer la sélection du menu.

Fonction callback externe du menu principal pour traiter les mouvements d'encodeur.

Cette fonction est appelée lorsque l'encodeur rotatif détecte une rotation. Elle met à jour la position actuelle dans le menu avec gestion circulaire et anti-rebond.

Parameters
directionDirection de rotation (>0: suivant, <0: précédent)
Precondition
direction doit être différent de 0
Postcondition
etatActuel est mis à jour et menuNeedsUpdate est activé

void handle_uart_reception ( )

Gère la réception des caractères UART du module Bluetooth.

Precondition
Module UART1 initialisé
Postcondition
Messages complets traités automatiquement

Cette fonction lit les caractères disponibles sur UART1, les stocke dans un buffer et détecte la fin des messages (caractères '
' ou '\r'). Les caractères reçus sont également renvoyés en écho sur UART2.

Precondition
Le module UART1 doit être initialisé et configuré
Postcondition
Le message complet est stocké dans receive_buffer si terminateur détecté

void process_received_message ( )

Traite les messages complets reçus via Bluetooth.

Precondition
Message complet dans le buffer de réception
Postcondition
Buffer réinitialisé après traitement

Traite les messages complets reçus via Bluetooth.

Analyse le premier caractère du message envoyé par l'application pour déterminer le type de commande et exécute l'action correspondante. Actuellement supporte :

  • 'z' : Réglage de la date et l'heure (format: z16:12:00;29/04/2005)
Precondition
Un message complet doit être présent dans receive_buffer
Postcondition
Le buffer de réception est réinitialisé après traitement
Note
Format attendu pour réglage date/heure : zHH:MM:SS;DD/MM/YYYY

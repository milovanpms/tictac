Detailed Description

Gestion de la machine à états pour l'interface utilisateur de mesure de pouls sur écran e-paper.

Author
Thomas Pineau et Milovan Paget

Ce fichier implémente une machine à états pour gérer l'interface utilisateur d'un système de mesure de pouls utilisant un écran e-paper. Il gère la navigation dans les menus, les transitions entre les différents états (menu, mesure, historique) et l'affichage des éléments graphiques sur l'écran e-paper.

Enumeration Type Documentation

◆ State_t

enum State_t

Énumération des états de la machine à états principale.

Cette énumération définit les différents états possibles du système :

  • MENU : Affichage du menu principal
  • MESURE : Mode de mesure du pouls
  • HISTORIQUE : Consultation de l'historique des mesures
  • IDLE : État d'attente avec timeout
  • DONE : État de fin, retour au menu

void EPD_Pouls_Display_MenuPouls ( void )

Initialise et affiche le menu principal de mesure de pouls.

Cette fonction configure les paramètres initiaux du menu (nombre d'états, état actuel) et déclenche l'affichage complet du menu avec ses cadres et indicateurs de sélection.

Precondition
L'écran e-paper doit être initialisé
Les variables globales nombreEtats, etatActuel et menuNeedsUpdate doivent être définies
Postcondition
Le menu est affiché avec l'état initial (état 1 sélectionné)
Les variables de gestion du menu sont initialisées

◆ EPD_Pouls_HandleMenuNavigation()

void EPD_Pouls_HandleMenuNavigation ( void )

Gestionnaire de la navigation dans le menu principal.

Cette fonction gère les interactions utilisateur dans le menu principal, notamment la détection des pressions sur le bouton central avec anti-rebond et la mise à jour de l'affichage du menu selon les sélections.

Precondition
L'écran e-paper doit être initialisé
Les variables globales etatActuel et menuNeedsUpdate doivent être définies
Postcondition
L'état de la machine peut changer vers MESURE ou HISTORIQUE selon la sélection
L'affichage du menu est mis à jour si nécessaire

◆ EPD_Pouls_StateMachine()

SM_State_t EPD_Pouls_StateMachine ( void )

Machine à états principale pour la gestion de l'interface de mesure de pouls.

Cette fonction implémente la logique de la machine à états principale qui gère les transitions entre les différents modes de l'application (menu, mesure, historique). Elle gère également le timeout d'inactivité et les retours automatiques au menu.

Returns
SM_State_t État de la machine à états (SM_RUNNING ou SM_FINISHED)
Precondition
Le système doit être initialisé correctement
Postcondition
L'état de la machine est mis à jour selon la logique définie

◆ EPD_Pouls_UpdateMenuDisplay()

void EPD_Pouls_UpdateMenuDisplay ( void )

Met à jour l'affichage du menu selon la sélection actuelle.

Cette fonction actualise les indicateurs visuels de sélection dans le menu (points remplis/vides) et les textes correspondants selon l'état actuel du menu. Elle gère la navigation circulaire entre les options.

Precondition
etatActuel doit être défini (1 ou 2)
Les bitmaps filledDot et emptyDot doivent être définis
La police PixeloidSans18 doit être disponible
Postcondition
L'affichage du menu est mis à jour avec la sélection actuelle
L'écran e-paper affiche partiellement les modifications

Detailed Description

Module de gestion de l'horloge temps réel (RTC)

Author
Milovan Paget

Ce module fournit une interface simplifiée pour l'initialisation et la lecture de l'horloge temps réel. Il permet d'obtenir la date et l'heure actuelles sous forme de chaînes de caractères formatées.

◆ RTC_Init()

void RTC_Init ( )

Initialise le module RTC avec les valeurs par défaut.

Cette fonction configure et initialise l'horloge temps réel avec une date et une heure par défaut (1er janvier, samedi, 00:00:00).

Precondition
Le système STM32G4 doit être initialisé
Postcondition
Le RTC est configuré et opérationnel avec les valeurs par défaut

Cette fonction configure et initialise l'horloge temps réel en utilisant les fonctions BSP. Elle définit une heure et une date par défaut puis lit les valeurs configurées pour s'assurer de la synchronisation.

Precondition
Le système doit être initialisé
Postcondition
Le RTC est configuré et opérationnel avec les valeurs par défaut (1er janvier, samedi, 00:00:00)

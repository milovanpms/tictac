Detailed Description

Interface pour la gestion de l'encodeur rotatif.

Author
Thomas Pineau et Milovan Paget

Ce fichier contient les déclarations des fonctions pour la gestion d'un encodeur rotatif avec détection de direction et anti-rebond.

void encoder_callback ( uint8_t pin)

Fonction de callback pour traiter les interruptions de l'encodeur.

Cette fonction est appelée lors des interruptions générées par les changements d'état de l'encodeur rotatif. Elle détermine la direction de rotation et met à jour les variables globales correspondantes.

Parameters
pinNuméro du pin ayant généré l'interruption
Precondition
Les GPIO de l'encodeur doivent être configurés avec interruptions
La fonction EPD_MenuEncoderCallback doit être définie
HAL_GetTick() doit être fonctionnel pour l'anti-rebond
Postcondition
Les variables globales encoderPos et lastPos sont mises à jour
La fonction EPD_MenuEncoderCallback est appelée avec la direction
Note
Implémente un anti-rebond de 5ms pour filtrer les parasites
Utilise une machine d'états pour détecter la direction de rotation
Affiche la direction sur la console (UP/DOWN)

Fonction de callback pour traiter les interruptions de l'encodeur.

Cette fonction implémente une machine d'états pour détecter la direction de rotation de l'encodeur. Elle utilise les transitions entre états pour déterminer si la rotation est horaire (CW) ou anti-horaire (CCW).

Parameters
pinNuméro du pin ayant généré l'interruption (non utilisé dans l'implémentation)
Precondition
Les GPIO PA12 et PB5 doivent être configurés avec interruptions
HAL_GetTick() doit retourner un timestamp valide
La fonction externe EPD_MenuEncoderCallback() doit être définie
Postcondition
encoderPos est incrémenté/décrémenté selon la direction
lastEncoderState et lastDebounceTime sont mis à jour
EPD_MenuEncoderCallback est appelée avec la direction détectée
Note
Anti-rebond de 5ms pour filtrer les parasites électriques

◆ readEncoder()

int readEncoder ( )

Lit la valeur codée actuelle de l'encodeur rotatif.

Cette fonction lit les états des deux pins de l'encodeur (MSB et LSB) et retourne une valeur codée sur 2 bits représentant l'état actuel.

Returns
int Valeur codée de l'encodeur (0-3)
  • Bit 1 (MSB) : état du pin gauche
  • Bit 0 (LSB) : état du pin droit
Precondition
Les GPIO des boutons gauche et droit doivent être configurés
Postcondition
Aucun changement d'état, fonction de lecture pure
Note
La valeur retournée est calculée comme : (MSB << 1) | LSB

Cette fonction lit les états des deux pins de l'encodeur rotatif et combine leurs valeurs pour former un code sur 2 bits.

Returns
int Valeur codée de l'encodeur (0-3)
  • 0 (00) : les deux pins sont à 0
  • 1 (01) : pin gauche=0, pin droit=1
  • 2 (10) : pin gauche=1, pin droit=0
  • 3 (11) : les deux pins sont à 1
Precondition
Les GPIO BTN_GAUCHE_GPIO/BTN_GAUCHE_PIN et BTN_DROIT_GPIO/BTN_DROIT_PIN doivent être configurés en entrée
Postcondition
Aucun changement d'état, fonction de lecture pure
Note
MSB = pin gauche, LSB = pin droit
Formule : (MSB << 1) | LSB

Detailed Description

Implémentation du système de mesure de fréquence cardiaque par PPG.

Author
Thomas Pineau et Milovan Paget

Ce module implémente un système complet de mesure de fréquence cardiaque utilisant un capteur photopléthysmographique (PPG) HW827. Il inclut :

  • Acquisition de données via ADC
  • Filtrage passe-bande du signal PPG
  • Détection de pics cardiaques
  • Calcul du BPM (battements par minute)

Le système échantillonne à ~71 Hz pendant ~10 secondes pour obtenir une mesure fiable de la fréquence cardiaque.

Applique un filtre passe-bande simplifié au signal PPG.

Applique un filtre passe-bande au signal PPG.

Implémente un filtrage en deux étapes :

  1. Filtre passe-bas par moyenne mobile sur 5 points (≈14.28 Hz)
  2. Filtre passe-haut par soustraction de la moyenne mobile

Cette approche centre le signal autour de zéro et atténue :

  • Les composantes haute fréquence (bruit)
  • Les variations lentes (mouvement, respiration)
Parameters
inputSignal PPG brut en float
outputSignal filtré centré autour de zéro
lenNombre d'échantillons à traiter (HW827_RECORDING_SIZE)
Precondition
input[] doit contenir len échantillons valides
output[] doit être alloué pour len échantillons
Postcondition
output[i] = input[i] - moyenne_mobile(input[i])
Note
Fenêtre de moyenne mobile : 5 échantillons
Gestion des bords par duplication des valeurs extrêmes
Fréquence de coupure passe-bas ≈ FS/5 = 14.28 Hz

float * bpm_moy )

Calcule la fréquence cardiaque en BPM à partir des données PPG.

Cette fonction effectue un traitement complet du signal PPG :

  1. Conversion des données brutes uint16_t vers float
  2. Application du filtre passe-bande (selon HW827_BYPASS_FILTER)
  3. Calcul des statistiques (moyenne, écart-type)
  4. Détection des pics avec seuil adaptatif
  5. Calcul du BPM moyen basé sur les intervalles entre pics
Parameters
nb_battementsPointeur vers le nombre de pics détectés
bpm_moyPointeur vers le BPM moyen calculé
Precondition
HW827_Recording_Process_1ms() doit avoir été appelée
nb_battements et bpm_moy doivent pointer vers des variables valides
Postcondition
*nb_battements = nombre de battements cardiaques détectés
*bpm_moy = fréquence cardiaque moyenne en BPM (0 si < 2 pics)
Note
Mode normal : seuil = 0.1 × écart-type du signal filtré
Mode bypass : seuil = max(0.1 × écart-type, 50) pour signal brut
Affiche des informations de debug détaillées sur la console
Calcul BPM : 60 / (intervalle_entre_pics_en_secondes)

Détecte les pics locaux dans un signal filtré

Recherche les maxima locaux qui satisfont trois conditions :

  1. Valeur supérieure au seuil donné
  2. Valeur supérieure aux échantillons adjacents (pic local)
  3. Distance minimale respectée avec le pic précédent
Parameters
signalSignal filtré à analyser
lenNombre d'échantillons dans le signal
thresholdSeuil minimal pour qu'un pic soit détecté
min_distDistance minimale en échantillons entre deux pics
peak_locsTableau de sortie contenant les indices des pics
Returns
Nombre total de pics détectés
Precondition
signal[] doit contenir len échantillons valides
peak_locs[] doit pouvoir contenir au moins len éléments
threshold > 0 et min_dist > 0
Postcondition
peak_locs[0..retval-1] contient les indices des pics détectés
Note
Évite les bords du signal (i = 1 à len-2)
Un pic est défini comme : signal[i] > signal[i-1] ET signal[i] > signal[i+1]
La distance minimale évite la détection de multiples pics pour un même battement

void HW827_Recording_Process_1ms ( void )

Enregistre les données PPG pendant environ 10 secondes.

Cette fonction acquiert 740 échantillons à une fréquence de 71 Hz (intervalle de 14ms) et les stocke dans le buffer hw827_data[]. Un indicateur de progression est affiché si le mode test est activé.

Precondition
HW827_Init() doit avoir été appelée
L'ADC doit être configuré et fonctionnel
Postcondition
hw827_data[] contient 740 échantillons PPG bruts
hw827_index est remis à zéro
Note
Fonction bloquante pendant environ 10.36 secondes
Affiche "[###...###]" si HW827_TEST_MODE = 1
Utilise HAL_Delay() pour respecter la fréquence d'échantillonnage
